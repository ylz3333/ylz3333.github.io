LLM Infrastructure / Featured project
InferMesh
ROUTEOBSERVEEVALUATE
PROJECT 01 · INFERENCE & OBSERVABILITY

One gateway. Visible decisions.

A unified gateway for compatible hosted and self-hosted LLMs, with policy-based routing, bounded failover, streaming responses, and a live control panel.

PythonFastAPIOpenTelemetryDocker
Inside the project

Routing weighs configured cost, observed latency, availability, and an explicit complexity tier. Request traces connect provider attempts, token usage, and outcomes. Includes offline fault fixtures, evaluation tooling, and Kubernetes deployment manifests.

A working portfolio implementation. Mock-mode verification is documented in the repository; production availability and Kubernetes deployment results are not claimed.

Research tooling / Featured project
ReproAgent
CLAIMEXPERIMENTEVIDENCE
PROJECT 02 · SCIENTIFIC REPRODUCTION

Give every result a paper trail.

An evidence-first reproduction workflow that connects registered paper claims to experiment runs, deterministic metric checks, and auditable evidence bundles.

PythonDockerSHA-256Research workflows
Inside the project

The Lite implementation combines claim discovery, per-seed execution, registered tolerance rules, and reports with source and artifact hashes. A GCN/Cora case study explores applying the workflow to a real research paper.

An experimental CLI project under active development, with optional model-assisted claim extraction and human review.
